# TED.renovation

Сайт ремонта квартир, домов и коммерческих помещений в Астане. HTML/CSS/JavaScript без сторонних зависимостей. Внешний вид и изображения сохранены из Sites.

## Локальный запуск

Установите Node.js 22 или новее и Git. В терминале выполните:

```sh
git clone https://github.com/TimurBusy/ted-renovation.git
cd ted-renovation
npm start
```

Затем откройте http://localhost:3000. Для приватного репозитория потребуется вход в GitHub с доступом к проекту. Устанавливать пакеты не требуется. Остановка: Ctrl+C. Проверка расчётов: `npm test`.

Не открывайте index.html двойным щелчком: JavaScript-модули требуют HTTP-сервера. Локальный сервер слушает только ваш компьютер и не публикует сайт в интернете.

## Где редактировать

- dist/config.mjs — контактный телефон, WhatsApp, клиентские диапазоны цен и пояснения.
- dist/index.html — тексты, структура и резервные ссылки контактов без JavaScript. При изменении номера обновите их тоже.
- dist/styles.css — оформление, адаптивность.
- dist/calculator.mjs — расчёты и текст запроса.
- dist/app.mjs — меню, галерея, диалоги, WhatsApp, локальные настройки.
- dist/assets — изображения и логотип.
- PRICING.md — источники и внутренние плановые затраты. Не входит в размещаемый сайт.

## Логика

Квартиры: диапазон стоимости работ без материалов. Дизайн: без проекта / свой дизайнер / дизайнер TED. Свой дизайнер не начисляется, услуги внешнего дизайнера клиент оплачивает отдельно. Отдельный дизайн-проект начисляется один раз. Дома и коммерческие помещения — индивидуальная смета без искусственной наценки. Площадь калькулятора: 20–500 м²; для иной площади используйте прямую кнопку WhatsApp.

WhatsApp открывает чат +7 776 804 18 74 с подготовленным текстом; отправку подтверждает посетитель. Сайт не отправляет сообщение сам и не имитирует успешную отправку. Текст запроса не сохраняется автоматически, параметры калькулятора хранятся только в браузере.

## Перед публичным запуском

Цены предварительные, выплаты мастерам и дизайнеру не согласованы. Сверьте PRICING.md с реальными сметами. Иллюстрации — подписанные AI-концепции, не выполненные работы. Не добавляйте вымышленные отзывы и гарантии. Сайт пока owner-only в Sites и noindex.

При смене домена обновите og:url и og:image в index.html. При разрешённом публичном запуске отдельно измените доступ и robots. Для хостинга в подпапке потребуется адаптировать абсолютные пути /assets, /styles.css и /app.mjs.

Публикуется только dist плюс служебный манифест Sites. Локальный сервер также отдаёт только dist. Не кладите внутренние расчёты и секреты внутрь dist. Репозиторий TimurBusy/ted-renovation приватный: внутренние расчёты не предназначены для публикации. Файл .openai/hosting.json нужен только для Sites; для локального запуска не требуется.

## Проверки

Проверены синтаксис JavaScript, 108 сочетаний расчёта и границы площади, включение/исключение дизайна. Браузерная визуальная проверка в текущей среде недоступна: перед рекламой проверить мобильное меню, галерею, диалоги и WhatsApp на настоящем телефоне.
