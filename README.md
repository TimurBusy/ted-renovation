# TED.renovation

Сайт ремонта квартир, домов и коммерческих помещений в Астане. HTML/CSS/JavaScript без сторонних зависимостей. Внешний вид и изображения сохранены из Sites.

## Локальный запуск

Установите Node.js 22 или новее и Git. В терминале выполните:

```sh
git clone https://github.com/TimurBusy/ted-renovation.git
cd ted-renovation
npm start
```

Затем откройте http://localhost:3000. Для приватного репозитория потребуется вход в GitHub с доступом к проекту. Устанавливать пакеты не требуется. Остановка: Ctrl+C. Проверка расчётов: `npm test`.

Не открывайте index.html двойным щелчком: JavaScript-модули требуют HTTP-сервера. Локальный сервер слушает только ваш компьютер и не публикует сайт в интернете.

## Где редактировать

- dist/config.mjs — контактный телефон, WhatsApp, клиентские диапазоны цен и пояснения.
- dist/index.html — тексты, структура и резервные ссылки контактов без JavaScript. При изменении номера обновите их тоже.
- dist/styles.css — оформление, адаптивность.
- dist/calculator.mjs — расчёты и текст запроса.
- dist/app.mjs — меню, галерея, диалоги, WhatsApp, локальные настройки.
- dist/assets — изображения и логотип.
- PRICING.md — источники и внутренние плановые затраты. Не входит в размещаемый сайт.

## Логика

Квартиры: диапазон стоимости работ без материалов. Дизайн: без проекта / свой дизайнер / дизайнер TED. Свой дизайнер не начисляется, услуги внешнего дизайнера клиент оплачивает отдельно. Отдельный дизайн-проект начисляется один раз. Дома и коммерческие помещения — индивидуальная смета без искусственной наценки. Площадь калькулятора: 20–500 м²; для иной площади используйте прямую кнопку WhatsApp.

WhatsApp открывает чат +7 776 804 18 74 с подготовленным текстом; отправку подтверждает посетитель. Сайт не отправляет сообщение сам и не имитирует успешную отправку. Текст запроса не сохраняется автоматически, параметры калькулятора хранятся только в браузере.

## Перед публичным запуском

Цены предварительные, выплаты мастерам и дизайнеру не согласованы. Сверьте PRICING.md с реальными сметами. Иллюстрации — подписанные AI-концепции, не выполненные работы. Не добавляйте вымышленные отзывы и гарантии. Сайт пока owner-only в Sites и noindex.

При смене домена обновите og:url и og:image в index.html. При разрешённом публичном запуске отдельно измените доступ и robots. Для хостинга в подпапке потребуется адаптировать абсолютные пути /assets, /styles.css и /app.mjs.

Публикуется только dist плюс служебный манифест Sites. Локальный сервер также отдаёт только dist. Не кладите внутренние расчёты и секреты внутрь dist. Репозиторий TimurBusy/ted-renovation приватный: внутренние расчёты не предназначены для публикации. Файл .openai/hosting.json нужен только для Sites; для локального запуска не требуется.

## Проверки

Проверены синтаксис JavaScript, 108 сочетаний расчёта и границы площади, включение/исключение дизайна. Браузерная визуальная проверка в текущей среде недоступна: перед рекламой проверить мобильное меню, галерею, диалоги и WhatsApp на настоящем телефоне.

## Конструктор комнаты

Открывается с главной страницы кнопкой «Собрать комнату» или по адресу http://127.0.0.1:3000/constructor после npm start. Также можно запустить START.cmd в корне проекта. Установка зависимостей не нужна. Если порт занят, остановите прежний локальный сервер перед запуском новой версии.

Одна прямоугольная или Г-образная комната: размеры, отделка и цвет каждой стены, пола и потолка, окна и двери, мебель с размерами и поворотом. На плане сверху мебель можно перетаскивать. Объёмный вид — условная изометрия со снятыми двумя стенами и потолком. Пересечения мебели и проходы проверяются визуально.

Проект автоматически сохраняется в браузере. JSON позволяет перенести его в другой браузер; PNG сохраняет текущий вид; TXT содержит задание на ремонт. Перед заменой или сбросом появляется подтверждение. WhatsApp открывает текст задания, PNG и JSON прикрепляются вручную. Сохранения на localhost, 127.0.0.1 и разных портах независимы — для переноса используйте JSON.

Объёмы вычисляются из размеров: стены за вычетом проёмов, плинтус за вычетом дверей. Материалы, мебель, техника и надзор не включены; стоимость работ — индивидуальная смета. Перед ремонтом нужны замер и техническая проверка.

Модули: dist/room-model.mjs (данные, проверка и расчёты), dist/room-render.mjs (визуализация), dist/constructor.mjs (интерфейс). npm test запускает тесты исходного калькулятора и конструктора. Проверены импорт JSON, экспорт PNG/TXT, проёмы, поворот мебели, восстановление, сброс, переход с главной, исходный калькулятор и окно заявки, мобильная компоновка. Публикация не выполнялась.

## Обновлённый интерфейс конструктора

Четыре шага: размеры → отделка → мебель → мой проект. Готовые расстановки гостиной, спальни и кабинета заменяют мебель с подтверждением, сохраняя размеры и отделку. Три готовых стиля, образцы покрытий и цвета, применение отделки ко всем стенам. Стену и мебель можно выбрать нажатием в сцене; все объекты также доступны через обычные элементы интерфейса. Нажатие на размеры под комнатой открывает их редактирование.

Мебель добавляется на свободное место, если оно есть; движение привязывается к стенам в пределах 12 см. Размеры и точные координаты мебели вводятся в сантиметрах. Предупреждения подсвечивают пересечения мебели, зону 80 см перед дверью и высокий шкаф перед окном — это предварительные подсказки, не проверка строительных норм и не расчёт направления открывания двери.

Кнопки отмены/повтора хранят до 60 изменений в текущем сеансе; история сбрасывается при перезагрузке страницы. Сам проект сохраняется в браузере, включая название и пожелания сразу при вводе. Старые JSON version: 1 совместимы. Экспорт/импорт и новая комната находятся в «Сохранить / открыть». Подробные объёмы работ раскрываются на шаге «Мой проект».

Модуль dist/room-editor.mjs содержит шаблоны, историю, размещение, привязку и предупреждения. Тесты дополнены проверками этих сценариев.

## Вращение и размеры комнаты

Объёмный вид: зажмите среднюю кнопку (колёсико) и двигайте мышь для вращения и наклона; прокрутка над сценой меняет масштаб. Кнопка «Вращать» включает вращение левой кнопкой. На сенсорном экране — движение пальцем; короткое касание выбирает объект. Также есть кнопки поворота/наклона, приближения и сброса вида. Камера не меняет геометрию и не занимает историю проекта. Ближние стены автоматически скрываются при повороте. Прежняя условная изометрия заменена вращаемой ортографической проекцией; это не фотореалистичный рендеринг.

«Размеры комнаты» открывает числа и ползунки. Длина и ширина теперь 2–20 м, высота 2–5 м. В режиме «Тянуть стены на плане» зелёный маркер справа меняет длину, снизу — ширину, в углу — оба размера. Перетягивание округляется до 10 см; точный ввод — до 1 см. Одно перетягивание отменяется одним нажатием ↶.

При уменьшении размеры мебели и проёмов сохраняются, их позиции при включённой адаптации сдвигаются внутрь. Если объекты всё равно не помещаются или проёмы накладываются, изменение отклоняется. Возможные пересечения мебели после сдвига показываются предупреждениями. Изменения размера сохраняются в JSON и учитываются в объёмах работ.

## Проёмы и схема открывания двери

Кнопка «Окна и двери» рядом со сценой открывает компактный редактор и план. Нажмите на голубую линию окна или коричневую линию двери и перетаскивайте её вдоль стены; подведите к другой стене для переноса. Положение округляется до сантиметра. Выход за границы ограничен, наложение проёмов отклоняется; при недопустимой позиции остаётся последняя допустимая. Перетягивание целиком отменяется одним действием. При редактировании проёмов маркеры размеров комнаты скрыты, чтобы не перекрывать захват окна/двери.

Для двери задаются петли у начала/конца проёма (слева/справа на горизонтальной стене, сверху/снизу на вертикальной) и открывание внутрь/наружу. План показывает полотно и пунктирную дугу на 90°. При наружном открывании обзор плана автоматически оставляет место для дуги. Проём выбирается и в объёмном виде, после чего редактируется на плане. Общие настройки комнаты скрываются, пока раскрыт редактор проёмов; сверните его для возврата к размерам.

Схема двери попадает в JSON и текст задания. Для старых файлов без hinge/swing используется условное открывание внутрь с петлями у начала проёма; это нужно уточнить на замере. Предупреждения проверяют попадание прямоугольной мебели в сектор открывания, но не заменяют техническую проверку, не моделируют помещения за дверью и толщину полотна.


### Форма комнаты и образцы отделки
На шаге «Размеры» доступны прямоугольник и Г-образная форма. Вырез можно поместить в любой из четырёх углов; его ширина и глубина задаются в метрах. Оставшиеся крылья не уже 1 м. Для Г-образной формы наружные габариты меняются численно, а длины всех шести стен подписаны на плане. Произвольный контур и несколько комнат пока не поддерживаются.

Площадь пола и потолка исключает вырез; отделка и проёмы рассчитываются по всем шести стенам. При смене формы мебель и проёмы перемещаются в допустимые позиции, не удаляются; если разместить их невозможно, изменение отклоняется. Изменения можно отменить. Сохранённые прямоугольные JSON версии 1 совместимы; новые файлы сохраняют shape и texture.

Образцы отделки: матовая краска, льняные, растительные и геометрические обои, минеральная штукатурка; светлый дуб, орех, камень и мрамор на полу. Текстуры генерируются локально, имеют заданный масштаб и изменяемый цвет. Это иллюстративные образцы, не фотографии конкретных товаров и не фотореалистичный рендер.


### Сравнение А / Б и реальные материалы
Кнопка «А / Б · Сравнить» в шапке открывает два независимых снимка комнаты. Сохранение в слот выполняется явно, замена заполненного слота требует подтверждения. Открытие варианта в редакторе отменяется обычной кнопкой Undo; сам слот не меняется. Слоты сохраняются отдельно в localStorage ted-comparison-v1 и экспортируются в TED-comparison.json (импорт до 400 КБ). Старый одиночный TED-room.json остаётся совместимым.

В разделе отделки раскрывается «Реальные материалы · каталог». Начальная подборка: Boråstapeter Cream Linen 4304, Soft Olive 4335 и Quick-Step Impressive IM1848. Названия, артикулы и характеристики сверены 15.11.2026 по официальным страницам, ссылки находятся в room-products.mjs и в карточках. Цены и наличие в Казахстане не заявляются. Фотографии не копировались: оригинальные фото открываются на сайте производителя; локальная визуализация использует приблизительную фактуру и оттенок.

Выбранный товар записывается в JSON и текст задания. При ручной смене цвета, отделки, образца или готового стиля привязка снимается, чтобы изменённый материал не выдавался за конкретный артикул. Применение ко всем стенам переносит и привязку. Проверки импорта отклоняют неизвестные товары и несовместимые поверхности.


### Предварительный список материалов
На шаге «Мой проект» кнопка «Что купить для ремонта?» открывает список с настраиваемым запасом 0–30% (начальное значение 10%, не норматив). materialPlan.reserve сохраняется в JSON, сравнении А/Б и текстовом задании. Отдельная выгрузка — TED-materials.txt.

Пол: площадь реального контура × (1 + запас), целые упаковки округляются вверх при известной площади упаковки. Плинтус: периметр минус ширина дверей, плюс запас. Обои Boråstapeter 4304 и 4335: 0,53 × 10,05 м, без раппорта; число полос округляется вверх отдельно для каждой стены, затем суммируется по артикулу. К высоте полосы добавляется 10 см на подрезку, к количеству полос — выбранный процент запаса. Проёмы не вычитаются из раскроя, остатки по ширине не переиспользуются между стенами; расчёт намеренно консервативный. Размеры Soft Olive сверены по официальной карточке, ссылка есть в каталоге.

Для условных обоев выдаётся только площадь с запасом и просьба выбрать товар для раскроя. Краска, штукатурка и потолок показываются в м² без выдуманных расходов. Клей, грунтовка, выравнивание, подложка, крепёж и расходники требуют отдельного подбора. Список не является готовым заказом.


### Бюджет по ценам пользователя
На шаге «Мой проект» — «Посчитать мой бюджет». Цены изначально пустые, валюта тенге. Пустое поле не считается нулём и отражается в числе неоценённых позиций. Ноль — явно бесплатная/исключённая пользователем позиция. Материалы и работы имеют отдельные подытоги; частичная сумма называется «Учтено».

Для известных обоев цена за рулон, для известного ламината за упаковку, для другого пола за м² с запасом, для плинтуса за погонный метр с запасом. Когда расход материала неизвестен, пользователь вводит сумму за всю позицию. Работы считаются по чистой площади/длине без закупочного запаса. Подготовка, инженерия и прочее вводятся одной суммой. Комплексные расценки нужно проверить на двойной учёт материалов.

Цены сохраняются по нажатию кнопки, в budget.prices; они доступны в JSON, вариантах А/Б, задании и отдельном TED-budget.txt. Материальные цены привязаны к составу поверхности и единице, поэтому замена материала не наследует цену другого товара. При пересохранении бюджета сохраняются только активные строки. При изменении размеров количество пересчитывается. Проверки ограничивают числовые значения и размер объекта при импорте. Цены не являются предложением TED.
